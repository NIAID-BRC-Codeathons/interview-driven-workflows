The Challenge 0:45 - 1:40

From Free-Form Intent to Runnable Science

What the Researcher Provides
Unstructured Natural Language
"I have Illumina paired-end RNA-seq of A549 lung cells infected with Ebola virus vs mock infection across 24 and 48 hours. I need transcript quantification with Salmon and differential expression with DESeq2..."
Conversational shorthand, omitted reference genomes, missing contrast designs, zero syntax.
The Hallucination Trap: A raw frontier LLM produces workflow YAML that looks plausible, but invariably hallucinates tool IDs, drops required parameters, and fails execution.
Why Prompt Engineering Fails in Production
  • Tool Shed Drifts: Wrapper versions, changesets, and tool IDs cannot be guessed from LLM weights.
  • Broken Collection Algebra: Confusing single datasets with paired collections (list:paired) breaks runtime job scheduling.
  • Silent Statistical Bugs: Setting incorrect degrees of freedom or naive header trimming discards real discoveries.
  • No Execution Feedback: Without a compiler and a deterministic test harness, errors are never diagnosed.
Our Codeathon Goal
Build an interview-driven system with deterministic validation rails, live registry search, and a closed-loop execution oracle that repairs its own failures.
[0:45 - 1:40] Talking Points:
• Why is this hard? Biologists speak in biology: "paired-end reads, Ebola infected cells, DESeq2".
• If you feed this into a chatbot, it writes YAML with made-up tool IDs, broken parameter trees, or invalid collection wiring. Worse, it might run and silently delete the top significant gene.
• Our mission: create an agentic architecture where every tool is pinned to real Tool Shed changesets, every step is schema-validated, and workflows are executed in Docker biocontainers against real test data before anyone calls them done.
Foundations · The Foundry Pattern 1:40 - 2:35

Principled Skills for Agents & Humans

"No serious engineering culture treats the compiled binary as the place you make changes."
01 · Source of Truth
Knowledge Base
Human-authored markdown notes, controlled tags, typed frontmatter, and upstream contracts.
02 · Action Spec
The Mold
A typed manifest of references + procedural skeleton. Carries load policy, placement, and oracles.
03 · Compiler
The Cast
Deterministic compiler. Resolves wiki-links, imports JSON schemas, and emits frozen skills.
04 · Verified Artifact
Skill + Provenance
Frozen agent skill bundle plus exact build log: which Mold, which target, which checks ran.
1. Upstream Authority: Copy contracts verbatim, don't paraphrase. 2. Deterministic Tools: Tools do deterministic work; LLMs translate. 3. Executable Rails: Validation gates before execution.
[1:40 - 2:35] Talking Points:
• To solve this, we used the Galaxy Workflow Foundry, pioneered by John Chilton.
• In the Foundry pattern, you never write an agent prompt by hand. You author a Knowledge Base and a Mold. The Mold declares exact references, CLI contracts, and evaluation properties.
• A compiler called 'cast' bundles this into a frozen skill. The agent gets small, deterministic slices with strict schemas, not a gigantic fuzzy context window.
• The mantra: "Deterministic tools do deterministic work." Static validation via gxwf and execution via Planemo are hard oracles that an LLM cannot argue with.

Findings · Grounded in Execution 7:00 - 8:00

Real Traps Found at the Research Edge

Click each discovery below to see how naive generation would have failed:
[7:00 - 8:00] Talking Points & Interactions:
• Here is the real value of running these pipelines: finding the traps that no synthetic benchmark can ever reveal.
• (Click Trap 1: DESeq2 Header Trap) - THIS IS HUGE. DESeq2's main output has NO header, but normalized counts DOES. The published IWC exemplar uses 'header_lines: 1' because it artificially injects a header beforehand. If an agent naively copied that, it would discard row 1. Row 1 is sorted by p-value. In this paper, Row 1 IS SCF1! Naive copy-paste destroys the scientific finding.
• (Click Trap 2: Shed Repo Pinning) - Planemo's workflow runner requires explicit 'tool_shed_repository' blocks in format2 YAML, or it silently skips tool installation.
• (Click Trap 3: Conda Prefix) - Conda shebang limits fail on deep paths. BioContainers in Docker solved it.

Summary · NIAID-BRCs AI Codeathon 2.0 9:35 - 10:00

Autonomous Science Needs Deterministic Rails

1. The Foundry Pattern
Keep source knowledge in typed Knowledge Bases. Cast frozen skills with explicit provenance. Never hand-maintain agent prompts.
2. Live Grounding
Query real registries via MCP. Use IDF token weighting. Automatically ask follow-up questions when inputs or organisms are ambiguous.
3. Closed-Loop Oracles
gxwf validate checks structure; planemo test in Docker checks execution. Errors trigger automated triage and repair loops.
