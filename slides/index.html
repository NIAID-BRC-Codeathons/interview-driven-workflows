The Challenge 0:45 - 1:40

Unstructured Intent vs. Deterministic Execution

Input from the Researcher
Natural Language Request
"I have Illumina paired-end RNA-seq of A549 lung cells infected with Ebola virus vs mock infection across 24 and 48 hours. I need transcript quantification with Salmon and differential expression with DESeq2."
Conversational shorthand, omitted reference genomes, missing contrast designs, zero workflow syntax.
The Hallucination Failure: Unconstrained frontier language models generate plausible YAML that fails at runtime due to fabricated tool IDs, omitted required inputs, and broken collection wiring.
Concrete Failure Modes in Production
  • Tool Shed Identifier Drift: Models cannot derive exact wrapper versions or changeset hashes from pretraining weights.
  • Broken Collection Algebra: Conflating individual datasets with paired collections (list:paired) aborts runtime scheduling.
  • Silent Statistical Errors: Setting invalid degrees of freedom or naive header stripping discards true biological signal.
  • Zero Execution Feedback: Without external compilers and test runners, errors remain undetected.
The Codeathon Commitment
Replace unconstrained prompt generation with deterministic compilation, live registry discovery, and automated execution oracles.
[0:45 - 1:40] Talking Points: Biologists communicate in intent, not workflow schemas. When frontier models generate workflow files without constraints, they fail. They hallucinate Tool Shed changesets. They break collection algebra by feeding lists into single-file ports. They set contradictory statistical parameters. A workflow that looks plausible but silently drops the top candidate gene is catastrophic. We replaced unconstrained generation with deterministic compilation.

The Foundry Pattern: Compiling Knowledge into Skills

"No serious engineering culture treats the compiled binary as the place you make changes."
01 · Source of Truth
Knowledge Base
Markdown notes, controlled registries, typed frontmatter, and upstream tool specifications.
02 · Action Spec
The Mold
Typed manifest of references plus procedural skeleton. Defines load policies, placement, and oracles.
03 · Compiler
The Cast
Deterministic compiler. Resolves links, imports schemas, and generates frozen skills.
04 · Verified Output
Skill + Provenance
Frozen agent skill bundle accompanied by complete build log and verification hashes.
1. Upstream Authority: Import contracts verbatim from Galaxy and Tool Shed. 2. Deterministic Tools: Tools execute deterministic work; models translate. 3. Executable Rails: Static validation gates precede execution.
[1:40 - 2:35] Talking Points: We ground this work in the Foundry Pattern designed by John Chilton. Traditional agent setups paste huge prompts and hope for the best. The Foundry treats prompts as compiled binaries. Humans maintain the Knowledge Base and Molds. A compiler called Cast builds frozen, versioned skills with complete provenance. The model translates; deterministic tools judge.

Findings · Grounded in Execution 7:00 - 8:00

Four Empirical Edge Traps Discovered During Execution

Click each discovery below to inspect how unverified generation fails in practice:
[7:00 - 8:00] Talking Points: Real execution exposes traps that static models cannot detect. First: DESeq2 outputs have asymmetric headers. The IWC workflow prepends a synthetic header and then skips it with header_lines: 1. If you copy that rule naively, you delete row 1. In this paper, row 1 is SCF1—the primary discovery of the study. Second: Planemo ignores tool IDs unless explicit tool_shed_repository blocks are defined in the YAML. Third: deep sandbox paths break conda's 128-character shebang limit, necessitating Docker BioContainers.
