# Real Interview Sources: Biostars

50 real bioinformatics questions from Biostars (biostars.org), a public
Q&A forum, obtained via the CC-BY-4.0-licensed dataset published on
Zenodo by Augustin Luna (https://zenodo.org/records/7813785) --
not scraped from the live site. Selected by hand from a larger
keyword-and-heuristic-filtered shortlist for being genuinely
workflow-shaped requests (data + an analysis goal), not troubleshooting,
installation, or purely conceptual questions.

Each file in raw/biostars-*.txt carries its own source header
(# source / # title / # date / # license). This file is the index.
